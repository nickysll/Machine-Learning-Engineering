# 🤖 Machine Learning Engineering Portfolio
### Tech Challenges desenvolvidos durante a Pós-Graduação FIAP

Repositório destinado à organização, desenvolvimento e versionamento dos projetos (Tech Challenges) realizados ao longo da Pós-Graduação em **Machine Learning Engineering** da **FIAP**.

Cada fase do curso possui seu próprio diretório, contendo código-fonte, notebooks, conjuntos de dados, modelos treinados, relatórios e testes. O objetivo é manter uma estrutura organizada, escalável e alinhada às boas práticas de desenvolvimento de software e projetos de Ciência de Dados.

Esse README seria editado conforme a evolução do curso.

## Estrutura do repositório

```text
.
├── README.md
├── pyproject.toml
├── tech-challenge-fase-xx
│   ├── README.md
│   ├── data
│   │   ├── external
│   │   ├── processed
│   │   └── raw
│   ├── models
│   ├── notebooks
│   ├── reports
│   │   └── figures
│   ├── src
│   └── tests
└── uv.lock
```

## Organização dos diretórios

| Diretório        | Descrição                                                   |
| ---------------- | ----------------------------------------------------------- |
| `data/raw`       | Dados originais, sem alterações.                            |
| `data/processed` | Dados tratados e prontos para utilização.                   |
| `data/external`  | Bases de dados obtidas de fontes externas.                  |
| `notebooks`      | Análises exploratórias e experimentos.                      |
| `src`            | Código-fonte do projeto.                                    |
| `models`         | Modelos treinados e artefatos gerados.                      |
| `reports`        | Relatórios, documentação e figuras utilizadas nas análises. |
| `tests`          | Testes automatizados do projeto.                            |

## Tecnologias

* Python 3.12+
* UV (gerenciamento de dependências)
* Git e GitHub
* Jupyter Notebook
* Visual Studio Code
* Ubuntu (WSL)

## Objetivos

* Organizar os projetos de forma padronizada.
* Aplicar boas práticas de desenvolvimento.
* Utilizar versionamento com Git.
* Documentar cada etapa dos Tech Challenges.
* Construir um portfólio técnico ao longo da pós-graduação.

## Boas práticas adotadas

Este repositório busca seguir princípios de desenvolvimento de software, incluindo:

* Organização modular dos projetos.
* Estrutura padronizada para Ciência de Dados.
* Versionamento com Git.
* Documentação contínua.
* Código limpo (*Clean Code*).
* Reprodutibilidade dos experimentos.
* Separação entre dados, código, modelos e documentação.
