# 🤖 Machine Learning Engineering Portfolio

### Tech Challenges desenvolvidos durante a Pós-Graduação FIAP

Este repositório reúne os projetos desenvolvidos ao longo da Pós-Graduação em **Machine Learning Engineering da FIAP**.

Cada Tech Challenge possui seu próprio diretório e documentação, acompanhando a evolução dos estudos desde a construção e avaliação de modelos até práticas de **MLOps, APIs, containerização, CI/CD, monitoramento e orquestração de pipelines**.

### 🏥 Fase 03

Projeto de **Machine Learning Engineering para classificação de textos médicos**, com foco no ciclo de vida de um modelo em produção.

A solução inclui:

- classificação com **TF-IDF + Logistic Regression**;
- API REST com **FastAPI**;
- testes automatizados com **Pytest**;
- análise estática com **Ruff**;
- containerização com **Docker e Docker Compose**;
- integração contínua com **GitHub Actions**;
- pipeline de treinamento com **Apache Airflow**;
- monitoramento com **Prometheus e Grafana**;
- análise de performance com **ONNX Runtime**;
- benchmarks de latência e throughput.
